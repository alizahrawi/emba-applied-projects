# EMBA Applied Projects

Practical, reusable experiments developed while studying Executive MBA topics.

This repository turns classroom concepts into small tools that can be tested, shared, and improved. Each project is documented independently and keeps its assumptions, limitations, and privacy choices visible.

## Use online

When GitHub Pages is enabled, open the repository's Pages URL. The landing page will take you to the latest project.

## Use locally

Download or clone the repository, then open the relevant `index.html` in a modern browser. No build step is required.

## Principles

- **Applied learning:** every project begins with a real classroom or organizational challenge.
- **Small and reusable:** projects should be understandable without a complex setup.
- **Privacy by design:** collect only what is necessary and explain how data is handled.
- **Responsible interpretation:** tools that touch personality or behavior are prompts for conversation, not diagnostic or hiring instruments.
